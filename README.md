Superstore Sales Analysis and Interactive Dashboard

Project Overview

This project focuses on analyzing Superstore sales data using Microsoft Excel. The objective is to explore sales and profit performance through data analysis, charts, and an interactive dashboard.

Tools Used

- Microsoft Excel
- Pivot Tables
- Charts and Data Visualization
- Excel Dashboard

Project Contents

This project includes the following analysis sheets:

1. Dashboard Interactive overview of the Superstore sales analysis.
2. Sales & Profit by Category Analysis of sales and profit across product categories.
3. Profit By Region Regional profit analysis.
4. Sales By Segment Sales analysis across customer segments.
5. Superstore Dataset Original dataset used for the analysis.

Key Activities

- Explored and organized the Superstore dataset.
- Analyzed sales and profit performance.
- Compared performance across categories, regions, and customer segments.
- Created charts and visualizations.
- Developed an interactive Excel dashboard.

Project Objective

To develop practical Excel skills and understand how data analysis and visualization can help businesses make better decisions.

Project Files

- "Superstore_Sales_Analysis.xlsx" Completed Excel analysis and dashboard.
- "Dashboard.png" Screenshot of the dashboard.

Conclusion

This project helped me gain practical experience in Microsoft Excel, data analysis, data visualization, and dashboard creation.
